# Burkardt Fortran 90 collection coverage

[Source repository](https://github.com/Beliavsky/Burkardt-Fortran-90-codes) at commit `de71b73e5ce47b24baba7af0f20a8409c9e8a495`. Reviewed 2026-11-18.

This initial addition covers **30 components** under one canonical repository entry. It is not a classification of every directory in the mirror. Programs, test directories, helper libraries and duplicate translations are not counted as separate GitHub repositories.

Each mapping has pinned normalized UTF-8/LF source hashes, procedure ranges and calling sequences where applicable in [the review ledger](local-reviews.md). Search the catalog for a component directory (such as `asa047`), routine name (such as `nelmin`), topic or GAMS class. The mathematical implementation/initialization and scope notes were inspected; **none of these programs or author examples was compiled or run for this addition**.

## Reuse and attribution

Licensing is component-specific. Many selected pages/headers state MIT. FFTPACK5 states GPL (version unspecified in the reviewed notice). The inspected QUADPACK DQAGS/DQAGI sections and component page have no license statement, while DGTSL and TIMESTAMP helpers in the same source file carry MIT notices. These helper notices are not treated as a blanket grant for the quadrature core. The collection is therefore shown as **custom/mixed**, not MIT or public domain as a whole. These classifications do not establish licensing for unreviewed files.

John Burkardt maintains/translates the collection, and source headers credit the original algorithm authors. The GitHub mirror belongs to Beliavsky; the account attribution must not be substituted for algorithm authorship.

Select complete required bundles and inspect helper dependencies, callbacks, numerical kinds, work arrays and status conventions. Do not compile every directory into one program: many bundles reuse names such as `timestamp`, `cholesky`, `step` and statistical helpers. No FPM manifest or playground execution support is implied.
